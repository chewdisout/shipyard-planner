# Палуба — Angular-прототип

Адаптивный прототип рабочего обзора супервайзера судостроения на Angular 21.

## Запуск

Требуется Node.js 22.12 или новее.

```powershell
npm install
npm start
```

Откройте адрес, показанный Angular CLI (обычно `http://localhost:4200`). Для сборки используйте `npm run build`.

## Что уже есть

- Обзор судна, палубы и зоны, план на день, прогресс, блокеры, приоритетные задачи и команда.
- Создание задачи, блокера, замечания или встречи.
- Для блокера обязательна фотография; она видна в карточке и открывается крупно.
- Привязка по поперечному фрейму и продольному L-шпангоуту, включая центральное положение L0.
- Страница команды: поиск и фильтры, добавление/удаление людей, редактирование палубы, зоны, задачи и времени освобождения.
- Вход для профиля V-A-N-D через Supabase Auth; задачи, фотографии, команда и заметки сохраняются через Supabase.

План встреч и исходные объёмы работ на главном экране пока демонстрационные. Облачные таблицы и защищённый вход должны быть включены до использования приложения.

## Подключение Supabase

В проект добавлен официальный клиент `@supabase/supabase-js`, конфигурация URL и Publishable key — в `src/environments/environment.ts`. Publishable key предназначен для браузера; пароль базы и `secret`/`service_role` ключи в Angular не добавлять.

Начальная схема лежит в `supabase/migrations/`. Она создаёт задачи, сотрудников, прогресс зон, заметки, включает RLS для доступа только владельцу и приватное хранилище фотографий. Чтобы применить схему к облачному проекту:

```powershell
npx supabase login
npx supabase link --project-ref gfkjrrcwffldcawxiiyn
npx supabase db push
```

CLI попросит пароль базы локально. Используй новый пароль после смены ранее отправленного. Перед запуском проверь SQL миграцию. Затем в Supabase Dashboard → Authentication → Users создай пользователя `chewdisout@gmail.com` и задай ему пароль. В приложении вход можно выполнить как по `V-A-N-D`, так и по этому email. Публичная регистрация в приложении не включена.

В Cloudflare Pages выставь build command `npm run build` и output directory `dist/shipyard-progress/browser`. После успешной сборки frontend использует Supabase напрямую по HTTPS; отдельный собственный сервер для API не нужен.

`prototype-standalone.html` — сохранённый исходный HTML-макет. Основное Angular-приложение находится в `src/app/`.
